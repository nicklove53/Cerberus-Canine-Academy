# Cerberus Canine Academy — Website

Professional dog training website for Ed McCallon / Cerberus Canine Academy LLC.

---

## 🚀 How to Deploy (GitHub + Vercel)

Follow these steps once and your site will be live with a shareable link.

---

### Step 1 — Create a GitHub Account
1. Go to [github.com](https://github.com) and sign up for a free account if you don't have one.

---

### Step 2 — Create a New Repository
1. Once logged in, click the **+** icon in the top right → **New repository**
2. Name it: `cerberus-canine-academy`
3. Set it to **Public**
4. Leave everything else as default
5. Click **Create repository**

---

### Step 3 — Upload the Files
1. On your new repository page, click **uploading an existing file**
2. Drag and drop BOTH files from this folder:
   - `index.html`
   - `vercel.json`
3. Scroll down and click **Commit changes**

---

### Step 4 — Create a Vercel Account
1. Go to [vercel.com](https://vercel.com)
2. Click **Sign Up** → choose **Continue with GitHub**
3. Authorize Vercel to access your GitHub

---

### Step 5 — Deploy on Vercel
1. On your Vercel dashboard, click **Add New → Project**
2. Find `cerberus-canine-academy` in the list and click **Import**
3. Leave all settings as default
4. Click **Deploy**
5. Wait about 30 seconds — Vercel will give you a live link like:
   `https://cerberus-canine-academy.vercel.app`

---

### Step 6 — Share Your Link
Copy the link Vercel gives you and share it with anyone!

---

## 🔄 Updating the Site Later
1. Go to your GitHub repository
2. Click on `index.html` → click the **pencil edit icon**
3. Make changes → click **Commit changes**
4. Vercel automatically re-deploys within ~30 seconds

---

## 📁 Files in This Package
- `index.html` — the full website (all images embedded)
- `vercel.json` — tells Vercel how to serve the site
- `README.md` — this instruction file
